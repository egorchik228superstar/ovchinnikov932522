# Лабораторная работа № 1. Задача коммивояжёра

## 1. Что сделано

Реализованы два алгоритма:

- Точный алгоритм: полный перебор маршрутов с помощью ручной
  реализации алгоритма Дейкстры построения перестановок.
  Находятся минимальная и максимальная стоимости.
- Эвристика ближайшего города: на каждом шаге выбирается
  ближайший непосещённый город. В конце выполняется
  возвращение в начальный город.

Для обоих алгоритмов время измеряется с помощью chrono.
Генерация случайных стоимостей выполняется с помощью random.

Качество эвристического решения:

Quality = 100 * (Max - Greedy) / (Max - Min)

100% соответствует лучшему решению, 0% — худшему.
Если Min = Max, качество принимается равным 100%.

## 4. Рост объёма вычислений

При фиксированном начальном городе рассматривается (N - 1)!
маршрутов. Вычисление стоимости каждого маршрута требует O(N)
операций. Общая сложность: O(N * (N - 1)!).

Дополнительные замеры полного перебора:

```text
N    Количество маршрутов    Время, мс
10                362880       7.56–9.73
11               3628800      85.42
12              39916800    1030.68
13             479001600   21024.40
```

При N = 13 один запуск занял около 21 секунды.
На данной машине с этой размерности серия запусков становится
затруднительной по времени.

Для N = 14 число маршрутов равно 6 227 020 800.
Измерение для этой размерности не проводилось.

Стоимость маршрута хранится в long long, количество маршрутов —
в unsigned long long. Для исследованных размеров переполнения нет.

Для 64-битного unsigned long long значение 20! ещё помещается,
а 21! уже превышает допустимый диапазон. Поэтому при N = 22
счётчика недостаточно для хранения числа всех маршрутов.
Ограничение по времени возникает значительно раньше.

## 5. Выводы

1. Полный перебор гарантированно находит лучший и худший
   маршруты, но число проверяемых вариантов растёт факториально.

2. Эвристика ближайшего города имеет сложность O(N²).
   На исследованных матрицах она работает значительно быстрее
   полного перебора, особенно при увеличении числа городов.

3. В 16 случайных экспериментах качество эвристики составило
   от 62.56% до 100%. В трёх случаях она нашла оптимальный маршрут.

4. На примере из лекции оба алгоритма нашли маршрут стоимостью 18.

5. Для небольшого числа городов полный перебор позволяет получить
   точное решение. При увеличении размерности эвристика позволяет
   существенно сократить время, но не гарантирует оптимальность.
